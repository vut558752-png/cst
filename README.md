# CST 俄罗斯方块

一个无需后端和构建工具的网页版俄罗斯方块。下载仓库后直接打开
`index.html` 即可游玩。

## 功能

- 七种经典方块和随机袋算法
- 幽灵落点、下一个方块预览
- 计分、消行、等级与逐级加速
- 本地保存最高分
- 暂停、重新开始和游戏结束提示
- 键盘与移动端触控操作

## 开始游戏

直接双击 `index.html`，或者在仓库目录启动任意静态文件服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作

| 按键 | 操作 |
| --- | --- |
| `←` / `→` | 左右移动 |
| `↓` | 加速下落 |
| `↑` / `X` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `Space` | 硬降 |
| `P` / `Esc` | 暂停或继续 |
